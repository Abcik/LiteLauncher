# LiteLauncher

LiteLauncher is a lightweight launcher for Minecraft: Java Edition, focused on a clean interface and straightforward version, profile, instance, loader, and modpack management.

Official website: https://litelauncher.net  
Discord: https://discord.com/invite/DJ2YYnS8YV

## Repository

- `Launcher/` — the main LiteLauncher client.
- `Bootstrap/` — bootstrap/update launcher.
- `Installers/` — current Windows, Linux, and macOS installer sources.

The launcher is developed for **Java 25**. Official installers download and manage the required Java runtime automatically.
