## Suggested pinned README intro

LiteLauncher is a lightweight Minecraft launcher. This repository exposes the trust-sensitive parts of the project — account handling, Microsoft sign-in, encrypted local session storage, updater/bootstrap logic, Minecraft version resolving, download verification, Java runtime handling and server distribution endpoints.

The official LiteLauncher visual shell is not included here. Pixel-perfect Swing scenes, custom text animations, bitmap font/glyph data, website presentation, artwork and production release infrastructure remain private to protect the official product identity.
