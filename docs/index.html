LiteLauncher Public Source

LiteLauncher is a lightweight Minecraft launcher project by Abcik. This repository publishes the audit-friendly parts of the launcher: installer behavior, bootstrap update flow, account/session handling, version resolving, downloads and game launch preparation.

The official pixel-perfect UI, glyph/font system, website presentation, production assets and release pipeline are intentionally not included.
