# Launcher module

This module keeps the backend/trust-sensitive launcher logic public:

- account/profile handling;
- Microsoft auth flow and local callback server;
- encrypted Microsoft session store;
- offline profile store;
- version list and version resolver;
- download service;
- Java runtime service;
- Minecraft launch command builder and game process startup.

The official Swing pixel UI and assets are redacted. See `../REDACTION.md`.
